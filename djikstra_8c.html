Runs djikstras on a array of Cells. Populates the dist and prev arrays.

This algorithm will always start at the top-left cell (CellID 0).

Parameters
mazeThe maze.
distPointer to an array to store the shortest distances from the start to each cell. Array should be size * size and indexed by CellID.
prevPointer to an array to store the previous cell in the shortest path to each cell. Array should be size * size and indexed by CellID.

Reconstructs the shortest path from the start to the target.

The start of the maze is always the top-left cell (CellID 0). If the path length is 0, either the target is unreachable or the target is the start.
